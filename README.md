# Student Spending & Budget Analyzer
### IEEE LGU Student Branch AI/ML Cohort One - Fall 2026

**Author:** Muhammad Hammad Atif

## Project Overview
This project is a data analysis exercise completed in Google Colab. It explores a fictional student spending dataset to uncover insights about expenses and payment habits. 

## Objectives
* Create and organize data using **Pandas**.
* Calculate summary statistics (totals, averages, maximums) using **NumPy**.
* Visualize the data by grouping categories and creating a bar chart using **Matplotlib**.
* Check data quality by identifying missing values and duplicate records.

## Files in this Repository
* `Week4_Student_Spending_Analyzer.ipynb`: The complete Google Colab notebook containing all code, data generation, and markdown explanations.
